# 日曜の朝、300回。

「動画で学ぶデータサイエンス」の学びと思い出を振り返る公開アーカイブです。

**公開サイト**  
https://hirasunaryou.github.io/data-science-sundays-dougademanabu_archive/

## はじめての公開設定

[Settings → Pages](https://github.com/hirasunaryou/data-science-sundays-dougademanabu_archive/settings/pages) を開き、次を設定します。

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**
- **Save** を押す

初回公開には数分かかる場合があります。以後は main の更新で自動的に再公開されます。

## できること

- 2020〜2026年の296日付を、年・テーマ・活動・用語で絞り込み
- 84日付の要約、節目、テーマをまたぐ復習ルート
- 当日視聴を照合できた19日付・21件の動画リンク
- 関心テーマ、情報共有テーマ、動画視聴／情報共有の記載の構成比
- 議事メモに残る時間の手がかりとconnpassメンバー一覧の確認値
- 8枚の投影モードと、みんなで振り返る25分の進め方

グラフは記録から読み取れた範囲の集計です。全Slack投稿の集計でも、全開催回の正確な時間測定でもありません。欠測をゼロとせず、各図の説明を合わせて読んでください。

## ファイルと更新

- `index.html`: サイト本体。データ・CSS・JavaScriptを内包した静的HTML
- `archive.csv`: 掲載日付・回番号・テーマの一覧
- `.nojekyll`: GitHub Pagesで静的ファイルをそのまま配信する指定

サイトの表示データは `index.html` 内の `archive-data` というJSONにまとまっています。記録を変更した際は、関連する集計とCSVも更新してください。

特定の日付へのリンクは `#entry-YYYY-MM-DD` です。例: `#entry-2020-11-29`。
ローカルでは `index.html` を開くだけで検索・グラフ・投影モードを使えます。外部教材の閲覧には通信が必要です。

## 公開範囲と資料

公開用の要約と、一般に見られる教材・イベントへのリンクを掲載しています。原本議事録、会議録画、会議パスワード、Slack招待URLは含めていません。

サイトは軽量なためGitHub内で配信できます。今後の動画や大きな資料は別の保存先に置き、一般公開が確認できたファイルだけをここからリンクする構成を想定しています。

## 公開情報の確認（2026-11-15）

参加者・登壇者の実名は役割表記に置き換えました。HTML内JSON・CSV・投影モードも同様です。公に提供された教材の著者名やチャンネル名、出典URLは、出典を明確にするため保持しています。外部サイトには氏名・アカウント名が表示される場合があります。

公開URLとリポジトリの所有者名はGitHubアカウント名を含みます。過去コミットには変更前の内容が残ります。今回、Git履歴の書き換えは行っていません。

connpass登録推移には、現在の一覧に載る人の登録年月のみを集計して使います。月別集計以外の名簿・スクリーンショット・個人別ログは公開リポジトリへ追加しません。全ページを確認するまで一部の行から全体の推移を推定しません。

以前掲載した3点のメンバー数は、検索取得時期から年月を割り当てていたため、歴史的推移の根拠として不十分と判断して掲載を取り下げました。現在は提供表344人（重複なし）と提供画面の管理者1人（2020年11月30日登録）を合わせた345人について、登録月別人数と累積人数を掲載しています。

## 登録時期のグラフ

`membership-monthly.json` / `membership-monthly.csv` は2026年11月15日に提供されたメンバー一覧を集計した月次データです。名簿は公開していません。現在の一覧に残る人を過去の登録月へ振り分けたものであり、退会済みの人を含む当時の総登録人数や実出席人数を復元したものではありません。

添付表344人をアカウントで重複検証し、全員の最終列「グループ登録日」を使用しました。「最新参加イベント開催日時」は使っていません。提供画面の管理者1人を加えた合計は345人です。年月のゼロ埋めは2020年11月〜2026年11月。2026年11月は15日時点です。

## 記録をたどる点の図

トップは以前の25列の点を並べたコンパクトなデザインを踏襲しています。第1回以降の掲載295日付を左上から右へ、行を折り返して日付順に配置し、各点から実際の年表項目へ移動できます。1点は1記録日であり、1回番号や1週間ではありません。事前準備の1日付は年表に残しています。

緑は開催記録、橙は年表に掲載した9つの節目、輪郭のみは中止、青は告知、破線の輪郭は日付要確認です。装飾的な濃淡や、記録がない日への補完はありません。2024年8月5日は原文の見出しが月曜日のため、日付を推測で修正せず要確認としています。

マウスを重ねるかキーボードで選択すると、点の下に日付と話題が表示されます。クリック・タップ・Enterで記録へ移動します。Tabで図に入り、矢印キー（上下は25点移動）、Home、Endで点を選択できます。
